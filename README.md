# Gym Management System

A Java-based Gym Management System developed as an academic project.

## Features

- Add gym members
- Manage regular and premium members
- Activate and deactivate memberships
- Track member attendance
- Upgrade memberships
- Process payments
- Calculate membership information
- Store member information

## Technologies Used

- Java
- Java Swing
- Object-Oriented Programming
- File Handling

## Main Classes

- `GymGUI.java` – Main graphical user interface
- `GymMember.java` – Base gym member class
- `RegularMember.java` – Regular membership class
- `PremiumMember.java` – Premium membership class

## How to Run

1. Install Java JDK.
2. Download or clone this repository.
3. Compile the Java files.
4. Run `GymGUI.java`.
